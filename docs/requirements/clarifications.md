# 赛题五答疑补充

来源：[参赛团队提供的腾讯答疑表](https://docs.qq.com/sheet/DTkVWbGxhQ3paendK?tab=CbZyBv)。读取日期：2026-10-16。以下按具体答复所在行整理；表头包含示例问答提示，正式通知与后续答复优先。

| 主题 | 答复内容摘要 | 表格行 |
|---|---|---|
| 初赛模板 | 暂不提供统一模板，可按作品提交大纲组织；决赛如统一模板将另行下发 | 7 |
| 初赛模型 | 建议高校参考赛题，自行约定初赛模型标准；决赛外挂调优方案原则上使用统一基座 | 7、10 |
| 服务器 | 决赛每高校一组资源；2vCPU、4GB、Ubuntu24.04；表中说明提交前15个工作日发放 | 16 |
| 无GPU | 统一环境不托管训练模型；训练后自行部署推理服务，通过API接入 | 19 |
| 微调证据 | 基座来源及许可、训练数据脚本、超参数、完整日志和曲线、适配器及加载资料 | 15 |
| 评审方式 | 初赛自行部署可访问网站，另交源码、登录和使用说明；评审直接登录测试 | 26、27 |
| 评分输入 | 评分以未公开的约100条数据为依据；已发约1000条结果建议入库备查，缺失会影响成果完整性 | 25—27 |
| 无效附件 | 可剔除或补采明显对应不上、打不开的采集异常，保留处理说明；评分集不包含这类异常 | 20 |
| 细粒度明细 | 附件披露更细明细时需逐条提取；未披露字段与逻辑推导字段需区分，推导数据不进入原文精度评分 | 8 |
| 产品供应商 | 按品牌单列合作次数和金额；同场投标不等同联合体，也不限于未中标者 | 6、9 |

表中提供了模型系列的文字说明，但未提供可直接使用的服务地址、账号、Key或基座权重。模型准确标识、参数规模、初赛校内约定及实际接入仍应按最终资源记录填写。
